# AI FAQ Chatbot

An AI-powered FAQ chatbot developed for the CodeAlpha Artificial Intelligence Internship.

## Features
- FAQ-based chatbot
- Text preprocessing
- TF-IDF Vectorization
- Cosine Similarity Matching
- Interactive Chat UI
- Match Confidence Score

## Technologies Used
- Python
- Streamlit
- Scikit-learn

## Run the Project
streamlit run faq_chatbot.py
